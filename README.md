# ShopSense — E-Commerce Customer & Sales Analytics Platform

## Problem Statement
An e-commerce marketplace wants to understand its sales performance, 
segment customers by purchasing behavior, predict customer satisfaction 
from order/delivery data, and surface these insights through a 
business-facing dashboard.

## Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle) — ~100,000 real 
order items, payments, products, sellers, geolocation, and reviews.

## Planned Build (staged)
- Phase A: Data understanding + EDA (single orders table first)
- Phase B: Merge relational tables + customer segmentation (RFM/K-means)
- Phase C: Predict review satisfaction from order/delivery features
- Phase D: SQL storage + dashboard (Power BI/Tableau) + Excel summary
- Phase E: Review-text sentiment/NLP + FastAPI + Docker deployment

## Tech Stack
Python, pandas, scikit-learn, SQL, Power BI/Tableau, FastAPI, Docker
